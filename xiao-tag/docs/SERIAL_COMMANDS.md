# Serial commands

Use newline termination in the serial monitor.

Commands:
- `help`
- `status`
- `preflight`
- `preflightjson`
- `keys`
- `join`
- `beacon`
- `beacon get`
- `beacon set <text>`
- `beacon save`
- `beacon reset`
- `autojoin get`
- `autojoin on`
- `autojoin off`
- `autojoin save`
- `autojoin reset`
- `cfgjson`
- `gpsjson`
- `rawjson`
