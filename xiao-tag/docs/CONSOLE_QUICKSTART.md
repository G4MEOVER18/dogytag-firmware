# Console quickstart

Kleiner Diagnose-Schritt für den seriellen Monitor.

## Befehle
- `help`
- `version`
- `uptime`
- `console`
- `status`
- `backend`
- `backendjson`
- `preflight`
- `preflightjson`
- `keys`
- `join`
- `beacon`, `beacon get`, `beacon set <text>`, `beacon save`, `beacon reset`
- `autojoin get`, `autojoin on`, `autojoin off`, `autojoin save`, `autojoin reset`
- `cfgjson`
- `gpsjson`
- `rawjson`
